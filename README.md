# Dissertation Project: Phishing Detection Using Heuristical Patterns

This repository contains the digital artefact developed as part of my undergraduate dissertation project. The project focuses on the identification and classification of malicious URLs (*phishing*) through the analysis of specific heuristical features.

## 🚀 Repository Content
* **`TFG_Phishing_Artifact_V1.ipynb`**: Google Colab notebook containing the synthesis of dataset features (including URL length, presence of the '@' symbol, and dot counts), data preprocessing, and the initial setup for machine learning training sets.

## 🛠️ Technologies & Libraries Used
* Python 3
* Pandas & NumPy (Data manipulation and simulation)
* Scikit-Learn (Dataset splitting and model selection)
* Google Colab (Development environment)

## 📋 How to Run the Project
To review and execute the analysis code:
1. Download the `.ipynb` file from this repository.
2. Upload the file to your personal [Google Colab](https://colab.research.google.com/) workspace.
3. Run the notebook cells sequentially to reproduce the findings.
